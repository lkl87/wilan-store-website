# متجر ويلان - الموقع + بوت تيليجرام

## هيكل المشروع

```
wilan-multipage/
├── index.html          صفحة الرئيسية
├── services.html        صفحة الخدمات (فيها كل الأسعار)
├── features.html         صفحة المميزات
├── faq.html               صفحة الأسئلة الشائعة
├── contact.html          صفحة التواصل
├── assets/
│   ├── css/style.css
│   └── js/
│       ├── config.js     ← هون بتحطي رابط السيرفر بعد رفعه
│       └── main.js
└── server/                السيرفر (بوت تيليجرام + استقبال الطلبات)
    ├── server.js
    ├── package.json
    ├── .env.example
    ├── data/               (الأسعار، العروض، الطلبات)
    └── README.md          ← دليل الإعداد الكامل خطوة بخطوة
```

## شو تغيّر بهاد النسخة؟

1. **الطلبات ما عاد تروح لواتساب** — صارت تنبعث تلقائياً لبوت تيليجرام مع:
   - صورة إشعار الدفع اللي بيرفعها الزبون
   - زرّين ✅ تأكيد الطلب / ❌ رفض الطلب
   - التاريخ واليوم والوقت
2. **الأسعار (بصفحة الخدمات) وشريط العروض** صار فيك تتحكمي فيهم من جوالك عبر أوامر البوت، بدون ما تلمسي كود الموقع.

## وين أبلش؟

روحي على مجلد `server/README.md` واتبعي الخطوات بالترتيب:
1. إنشاء البوت من BotFather
2. معرفة آيدي الشات تبعك
3. تشغيل السيرفر ورفعه أونلاين (Render / Railway / VPS)
4. تحديث `assets/js/config.js` برابط السيرفر

⚠️ **مهم:** الموقع (الصفحات HTML) لحاله ما بيكفي — لازم سيرفر `server/` يكون شغال حتى تشتغل ميزة التليجرام. لحد ما ترفعيه، الموقع رح يشتغل عادي بس الطلبات ما رح توصل وبتظهر رسالة "تعذر إرسال الطلب".
